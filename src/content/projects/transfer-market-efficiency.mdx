Every summer, clubs across Europe's top five leagues spend enormous sums moving players between one another. Most public coverage asks how much clubs spend. This project asks a different question: **did the spending work?**

It scores every club in the Premier League, La Liga, Serie A, the Bundesliga and Ligue 1 across seven complete seasons, from 2017/18 to 2023/24. Efficiency is measured per club and per season rather than as a single seven-year average, so the analysis can show which clubs improved over time.

<Callout type="decision" title="Why the scored window is 2017/18–2023/24">
  The window starts with the first big-five season that has the advanced statistics the scoring depends on. It ends at 2023/24, the last season for which a complete copy of that data still exists after FBref's Opta-sourced advanced statistics were removed in January 2026. Later transfer windows are not scored.
</Callout>

## How the analysis is built

The project runs as a reproducible pipeline, from frozen, checksummed source data to a Power BI dashboard. Each scoring step computed in R is recomputed independently in SQL, and a run fails unless the two agree.
